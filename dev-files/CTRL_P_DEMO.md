# Ctrl+P Layout Toggle Demo 🔄

Press **Ctrl+P** to toggle between layouts!

## Layouts Available

### Side-by-side (Default)
- Editor: 70% width (left)
- Preview: 30% width (right)
- Status bar shows: **[Side]**

### Top-bottom
- Editor: 70% height (top)
- Preview: 30% height (bottom)
- Status bar shows: **[Bottom]**

## How to Use

1. Start editing your markdown file
2. Press **Ctrl+P** at any time
3. Watch the layout switch instantly!
4. The status bar shows which layout is active

## Why Toggle?

**Use Side layout when:**
- Working on wide screens
- Want to see more content side-by-side
- Comparing markdown with rendered output

**Use Bottom layout when:**
- Working on narrow terminals
- Want more editor width
- Focus on writing with quick preview checks

Try it now - press **Ctrl+P**! 🎉
